## ✨ 功能特点

### 🎹 Blues 即兴练习

全功能的Blues练习系统，包含完整的虚拟乐队伴奏：

#### 🎼 音阶练习
- **三种Blues音阶**：小调Blues、大调Blues、Mixolydian
- **12个调式选择**：支持所有大调和半音调
- **可视化指板**：实时显示音阶位置，根音高亮
- **音符标注**：清晰显示每个音符在指板上的位置
- **品位标记**：
  - 顶部和底部双重品位数字标记
  - 特殊品位（3、5、7、9、12、15、17、19品）使用黄色高亮
  - 清晰的品位范围显示

#### 🎹 和弦进行练习
- **标准12小节Blues进行**：经典I-IV-V进行
- **快速6小节进行**：适合快速练习
- **实时和弦显示**：当前演奏和弦高亮提示
- **BPM速度控制**：
  - 滑动条调节（60-180 BPM）
  - 6个快捷按钮（60/80/100/120/140/160）
  - 实时节拍指示器
  - 速度描述提示（慢速/中速/快速/极速）

#### 🥁 鼓声节奏
- **三种节奏型**：
  - Shuffle：Blues摇摆节奏
  - Standard：标准四四拍
  - Slow Blues：慢板Blues
- **音量独立控制**：0-100%可调
- **实时拍号显示**：4拍可视化指示器

#### 🎺 Blues 伴奏系统
- **🎹 原生合成伴奏**：
  - **🎵 口琴伴奏**：
    - 模拟真实口琴音色（多振荡器合成 + LFO颤音）
    - 在强拍（1、3拍）演奏Blues Riff
    - 独立音量控制
  - **🎸 吉他伴奏**：
    - Karplus-Strong算法模拟拨弦音色
    - 跟随和弦进行自动演奏
    - 支持扫弦和闷音效果
    - 自动生成属七和弦
    - 独立音量控制
- **🎸 经典音频伴奏**（新增）：
  - 使用真实录音的Blues伴奏音轨
  - **智能预加载**：页面加载时自动预加载所有可用音频，确保播放无延迟
  - **保音高速度调节**：根据BPM实时调整播放速度，同时保持伴奏原调（当前界面范围 60-180 BPM）
  - **无缝循环播放**：支持设置循环起止点
  - **可视化状态**：绿点标识已预加载的调性
  - 支持12个调性（目前已配置A调）

#### 🎵 节奏训练
- 多种Blues节奏型练习
- 节拍器功能
- BPM可调节

#### ✨ 即兴创作
- 综合实战练习
- 音阶、和弦、节奏融合

### 🎼 和弦查找器

丰富的和弦库和指法图解：

- **常用和弦指法**：大三、小三、七和弦等多种类型
- **交互式指板显示**：清晰的可视化指法图
- **多维度筛选**：按和弦类型和根音快速查找
- **替代指法支持**：提供多种演奏选择

### 🎵 吉他调音器

### 📊 页面访问统计（新增）

无需后端数据库的本地访问统计功能：

- **实时统计**：自动记录每个页面的访问次数
- **访客分析**：
  - 总访问次数统计
  - 访问页面数统计
  - 会话次数统计（30分钟超时）
  - 今日访问次数
- **热门页面排行**：按访问次数展示 Top 5 页面
- **时间追踪**：记录首次访问和最后访问时间
- **数据管理**：
  - 导出统计数据（JSON格式）
  - 清除所有统计数据
  - 数据导入恢复功能
- **隐私保护**：所有数据存储在浏览器本地 localStorage，不上传服务器
- **悬浮展示**：右下角悬浮按钮，点击展开详细统计面板

精准的实时调音工具，帮助你快速调好吉他：

- **实时音频分析**：Web Audio API 时域采样 + Pitchy 的 McLeod Pitch Method（MPM），带音量门限、置信度筛选和中值平滑
- **标准调音支持**：支持6根弦标准调音 (E2, A2, D3, G3, B3, E4)
- **可视化反馈**：
  - 实时频率显示
  - 音分偏差指示器（±50音分范围）
  - 颜色编码精度提示（绿色=完美，黄色=接近，红色=偏离）
- **自动 / 手动选弦**：自动匹配最近的空弦，也可点击锁定目标弦；显示真实音名、八度和音分偏差
- **调弦与校准**：标准调弦、Drop D、降半音；A4 可选 432 Hz、438–445 Hz
- **听音辅助**：目标弦基准音、可展开的 C2–B4 钢琴键盘；播放期间暂停识音，避免扬声器被识别为琴声
- **资源管理**：停止、离开页面或切到后台时停止录音并释放麦克风


## 🛠️ 技术栈

### 核心技术
- **前端框架**：React 18
- **构建工具**：Vite
- **路由**：React Router 6（HashRouter）
- **样式**：Tailwind CSS
- **动画**：Framer Motion

### 音频技术
- **Web Audio API**：实时音频处理和分析
- **MPM 算法**：Pitchy 检测时域信号的周期性，筛除低音量和低置信度输入
- **音频合成**：
  - 振荡器（Oscillator）
  - 增益控制（Gain）
  - 滤波器（BiquadFilter）
  - LFO（低频振荡器）
- **保音高变速**：经典录音伴奏使用 SoundTouchJS AudioWorklet 处理速度变化

## 🚀 快速开始

### 前提条件

- Node.js 20.19+ 或 22.12+
- npm（统一使用 `package-lock.json`，不要生成 `yarn.lock`）

### 安装依赖

```bash
npm install
```

### 本地开发

```bash
npm run dev
```

访问 `http://localhost:5173` 即可查看应用

```bash
npm run build
```

构建产物将输出到 `dist` 目录

## 📦 部署

### 部署到 Cloudflare Pages

项目已连接 GitHub 的 `main` 分支。构建命令使用 `npm run build`，输出目录为 `dist`，根目录留空。推送代码后由 Cloudflare 自动构建和部署。

依赖统一使用 npm，提交并维护 `package-lock.json`；`.node-version` 固定 Node.js 22，`package.json` 声明 npm 10.9.2。CI 可用 `npm ci` 干净安装后执行构建。不要同时提交 Yarn 锁文件，否则 Cloudflare 可能自动选择 Yarn 4，迁移旧锁文件时因 CI 禁止修改而报 `YN0028`。

如果控制台已有 `NODE_VERSION` 环境变量，请与 `.node-version` 保持一致。若明确配置了 Yarn 安装命令，应改回 npm；修复后查看新提交的部署记录。部署成功后可通过 [Blues 练习](https://little-guitar.pages.dev/#/blues) 和 [调音器](https://little-guitar.pages.dev/#/tuner) 验证。

## 📖 使用指南

### 🎵 调音器使用

1. 点击导航栏进入"调音器"页面
2. 点击"开始调音"按钮（浏览器会请求麦克风权限）
3. 选择要调的弦（1-6弦）
4. 弹奏对应的弦，观察：
   - **频率显示**：当前检测到的频率
   - **音符显示**：最接近的音符
   - **指针位置**：偏左=音低，偏右=音高，居中=准确（±5 音分）
   - **颜色提示**：绿色=完美，黄色=接近，红色=需调整
5. 根据指示调整琴弦松紧，直到指针居中且显示绿色

### 🎹 Blues 练习使用

1. 进入"Blues 即兴"页面
2. 选择练习模式：
   - **和弦进行**：练习Blues和弦变化
   - **音阶练习**：学习Blues音阶位置
   - **节奏训练**：培养节奏感
   - **即兴创作**：综合实战

#### 和弦进行练习步骤：
1. 选择调式（A、C、E、G等）
2. 选择进行类型（12小节/6小节）
3. 调整BPM速度（建议初学者从60-80开始）
4. 配置伴奏：
   - 开启鼓声，选择节奏型
   - 可选：开启口琴伴奏
   - 可选：开启吉他伴奏
5. 点击"播放"开始练习
6. 跟随高亮的和弦提示演奏

### 🎼 和弦查找器使用

1. 进入"和弦查找"页面
2. 选择根音（C、D、E等）
3. 选择和弦类型（大三、小三、七和弦等）
4. 查看指法图：
   - 黑点表示按弦位置
   - 数字表示使用的手指
   - X表示不弹该弦
   - O表示空弦
5. 查看和弦组成音信息

## 调音器本地开发与验证

```bash
npm install
npm run dev
# 打开终端实际输出的地址（默认 http://127.0.0.1:5173/#/tuner）
npm run test:tuner
npm run build
```

调音器为纯前端功能，不依赖云函数或数据库，录音不会上传。原有 CloudBase 匿名登录在后台执行，不阻塞本地页面。已有云环境和托管信息见上文；本次调音器改动没有新增云资源。

麦克风需要 HTTPS 或 localhost / 127.0.0.1 安全上下文。一次弹一根空弦并静音其他弦；自动模式根据最近空弦选择目标，偏差很大时应手动锁定琴弦，确认目标八度后再缓慢调节。它不是多音和弦识别器。无有效信号约 350 ms 后清除读数。切到后台会停止调音，回来后需重新点击开始。

`test:tuner` 验证 216 组音频案例：44.1/48 kHz、三种调弦的六根弦、失谐、强泛音和带噪信号（误差小于 2 音分），另覆盖静音、直流偏移、随机噪声、切弦、八度边界和 A4 校准。合成信号验证不能替代真实设备试弹；建议用实际吉他检查六根弦、麦克风权限拒绝与重试、停止后系统录音指示消失等流程。

### 麦克风已连接但电平不动

- 调音器支持选择输入设备，并显示当前实际使用的麦克风名称；切换时会自动重新连接。蓝牙耳机、虚拟声卡、外接声卡可能与电脑内置麦克风不同。
- 输入电平独立于音高门限显示，同时标注 dBFS；连续约 2 秒没有采样信号会显示排查提示。系统暂停音轨、音频引擎暂停、输入太小也有独立提示。
- 授权后再次恢复 AudioContext，采样链路连接至零增益输出，保持音频图持续运行且不回放麦克风声音。
- 如仍无信号，检查系统声音设置的输入设备和输入音量、硬件静音，以及浏览器/宿主应用的麦克风权限；也可用 Chrome 或 Safari 打开本地地址交叉验证。
- `npm run test:tuner` 同时运行音频链路模拟测试，覆盖授权中断恢复、静音/弱输入/暂停诊断、采样到识音、切换设备和资源释放；真实硬件仍需试弹确认。

## 界面风格

全站固定使用浅色主题：白色卡片、浅灰页面背景、深灰文字，以绿色表示选中和主要操作，琥珀色表示根音和当前小节。导航、页脚、调音器及 Blues 四种练习模式统一使用这一风格，不随系统深色模式切换。

全局基础样式与主题变量位于 `src/index.css`，导航、播放栏和页面共用样式位于 `src/App.css`，调音器局部样式位于 `src/pages/TunerPage.css`。练习组件通过 Tailwind 工具类及 `practice-panel`、`practice-selected` 等共用类维护外观；音频逻辑无需随样式修改。
